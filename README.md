# 🌾 AgroJoner - Site Institucional

Site estático desenvolvido como trabalho acadêmico, com foco em uma empresa real: **Joner Agroutilidades**. O objetivo do projeto foi criar um site funcional, moderno e responsivo para divulgar os produtos e a história da empresa.

## 📌 Link do Site

Acesse o site publicado pelo GitHub Pages:  
➡️ [Agrojoner](https://nikimorona.github.io/agrojoner/)

---

## 🧾 Sobre a Empresa

A **Joner Agroutilidades** é uma empresa familiar fundada em 2017, em homenagem a Aloisio Laurentino Joner. Atua na comercialização de produtos agropecuários e utensílios para uso rural e urbano. O objetivo principal é oferecer produtos de qualidade com atendimento confiável e próximo.

---

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Google Maps API (localização)  
- Font Awesome (ícones)

---

## 🧩 Funcionalidades

- Página inicial com carrossel de imagens
- Seção institucional ("Sobre nós") com a história da empresa
- Catálogo de produtos dividido por categorias
- Integração com redes sociais (Facebook, Instagram, WhatsApp)
- Botão de contato via WhatsApp fixo
- Seção com localização via mapa
- Informações de contato visíveis
- Layout responsivo para dispositivos móveis
